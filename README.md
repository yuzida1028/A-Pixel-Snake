# Pixel Snake 贪吃蛇小游戏

一个本地运行的像素风贪吃蛇小游戏，使用 Node.js 提供静态服务，前端使用 HTML、CSS、JavaScript 和 Canvas 绘制。

## 安装与启动

```bash
npm install
npm start
```

启动后访问：

```text
http://localhost:3000
```

默认端口是 `3000`。如果需要临时换端口，可以在启动前设置 `PORT` 环境变量。

## 操作方法

- `W`：向上
- `A`：向左
- `S`：向下
- `D`：向右
- `Space`：暂停或继续
- `开始游戏`：从准备状态开始
- `暂停 / 继续`：暂停或恢复当前局
- `重新开始`：清空当前局并立即开始新一局

窗口失焦或切换到其他标签页时，游戏会自动暂停。

## 设置项

设置会保存到浏览器本地，刷新后自动恢复。

- 页面背景颜色
- 游戏区域背景颜色
- 蛇头颜色
- 蛇身颜色
- 豆子颜色
- 地图边界颜色
- 豆子生成间隔：`0.5s` 到 `5s`，默认 `2s`

豆子生成间隔只控制新增豆子的时间间隔，不影响蛇的移动速度。地图上最多同时存在 10 个豆子。

## 已实现功能

- 蛇、豆子、网格地图和边界绘制
- WASD 与方向键控制转向
- 禁止直接反向移动，并处理连续快速按键队列
- 吃豆增长、加分、更新历史最高分
- 撞墙、撞身体后结束游戏
- 未吃豆时允许蛇头进入本回合移走的原尾巴格
- 开始、暂停 / 继续、重新开始
- 空格暂停 / 继续
- 游戏结束后无需刷新即可重新开始
- 蛇占满地图时显示胜利提示
- 多豆子生成、上限控制、空闲格检测和安全跳过
- 暂停、未开始、结束时停止移动和豆子生成
- 颜色和豆子间隔修改立即生效并持久化
- 页面失焦自动暂停
